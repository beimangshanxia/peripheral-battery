# 外设电量

原生 macOS 菜单栏应用。每台有读数的外设在菜单栏显示自己的设备图标和电量，低电量会加上感叹号。点击可查看设备名称和详情。耳机在菜单栏显示该设备的最低读数，菜单内分别显示已上报的左右耳和充电盒电量。

## 制作原因

因为作者懒得打开设置-蓝牙看设备电量，不喜轻喷

## 使用

1. 按下方的「构建」说明生成应用，或在 Finder 打开已经构建好的 `dist/PeripheralBattery.app`。然后点击菜单栏上的外设图标。
2. 选择「启用低电量通知…」并允许系统通知。可以用「发送测试通知」确认。
3. 想读取更多蓝牙设备时，选择「启用蓝牙电量读取…」并允许蓝牙访问。

程序每分钟刷新一次，也可以手动刷新。低电量默认阈值为 20%，可以在菜单调整。一次低电量只提醒一次，充电恢复到阈值以上至少 3 个百分点后，下次降到阈值时会再次提醒。应用需要保持运行才能发送提醒。

## 设备兼容性

- **蓝牙**支持 macOS 上报电量的已连接设备，例如 Xbox Wireless Controller，也支持系统已连接并公开标准 Battery Service 的低功耗蓝牙设备。
- **USB / 2.4 GHz**支持通过系统属性或标准 USB HID 电量字段上报读数的设备。只暴露厂商私有协议的接收器需要对应型号的协议支持。设备显示「未报告电量」时，应用没有可用读数。

## 构建

需要 macOS 13 或更新版本和 Swift 6 工具链。运行 `bash ./script/build_and_run.sh` 构建并打开应用，或使用 Codex 的 Run 操作。运行 `bash ./script/swiftpm.sh test` 测试。
